# 🍉 合成大西瓜 · 照片版

用真人照片当素材的《合成大西瓜》。

和普通版本最大的区别：**角色的碰撞体积是照片里人物的真实轮廓**，
不是套一个圆形 —— 头、肩膀、胳膊、腿的形状都算进去，
所以两个人是"真的贴上"才会碰，不会像圆形那样看起来还离得远就撞上了。

## 开始玩

直接在浏览器打开 `index.html`，或者访问：

```
https://你的用户名.github.io/仓库名/
```

## 怎么玩

- 鼠标左右移动 → 决定人从哪个位置掉下来
- 点一下鼠标（或按空格）→ 放人
- 两个**一模一样大**的碰到一起 → 合成更大的一个
- 球堆过上面的红色虚线 → 游戏结束
- 手机上：手指拖动瞄准，抬手放人

## 想换成自己的照片

游戏本身不依赖任何服务器，也不联网。想改的话：

- `config.js` —— 难度、手感、外观，都在这里改（有中文注释）
- `images/1.png` ~ `images/11.png` —— 11 个等级用的人物图片
- `images-meta.js` —— 每个人物的碰撞轮廓数据（自动生成，别手改）
